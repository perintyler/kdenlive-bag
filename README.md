# Kdenlive (Barry Pack)

Headless video compositing, timeline assembly, and rendering to mp4 via MLT.

## Tools

- `kdenlive_status` — check melt/ffprobe installation and available codecs
- `kdenlive_render` — render a .kdenlive or .mlt project file to mp4
- `kdenlive_compose` — compose a video from clips, transitions, and filters, then render to mp4
- `kdenlive_project_info` — parse a .kdenlive/.mlt project and return a structured summary
- `kdenlive_probe_media` — probe a media file for duration, resolution, fps, and codec info
- `kdenlive_run_melt` — run an arbitrary melt command
- `kdenlive_list_transitions` — list available MLT transitions, filters, or producers

## Skills

- `video-editing` — video editing workflow guidance
